# Spark Media Services branding

This Spark Systems fork produces the Android TV / Fire TV application ID
`com.sparksystems.sms.tv` (`.debug` for debug builds).

The Gradle source namespace remains `org.jellyfin.androidtv` intentionally. It
is an implementation namespace with extensive upstream references; changing it
is not required for the Android application identity and would make future
upstream synchronization unnecessarily risky.

This is a derivative of Jellyfin for Android TV. Keep `LICENSE`, all upstream
notices, and the complete corresponding source available with every release.
